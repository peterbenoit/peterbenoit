# Peter Benoit

**Senior UI Engineer / Design Systems Architect / Accessibility Specialist**

---

I’m a senior UI engineer who turns complex design challenges into fast, accessible web experiences.
My work powers **CDC.gov** (billions of visits annually), **Coke.com**, **Harley‑Davidson.com**, and more.

-   Gold **w3 Award** winner (Federal Websites)
-   Deque‑certified accessibility specialist
-   Creator of the CDC.gov Template Package adopted across 500+ sites
-   
Off the clock you’ll find me hiking 🥾, gaming 🎮, or chasing quiet back‑roads 🚗.

## 🏆 Career Highlights

-   Engineered real‑time COVID dashboards viewed by millions, optimised with D3.js
-   Built cross‑platform Android & Samsung Smart TV apps for AutoTrader, adding 1 M+ users
-   Led accessibility reviews for Section 508 & WCAG 2.1 across large federal properties
-   Speaker & mentor on design systems, performance, and inclusive UX

While my public profile highlights some of my work, the majority of my contributions, commits, pull requests, and code reviews—are done in private repositories for the CDC.
